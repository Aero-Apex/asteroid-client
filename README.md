# Asteroid Client

An unofficial native mod for Horizon, an unofficial Rust rewrite of Minecraft Java Edition 26.3.
Not made, endorsed or supported by Horizon, Mojang or Microsoft.

- `asteroid-client/` is the mod (mixin bundle, pinned to Horizon commit 66f3981).
- `tools/` has the macOS build and test scripts. `MAC-NOTES.md` explains the setup and the test results.

Module names and behaviour are modelled on Meteor Client; the pathing is modelled on Baritone.
No code from either project is used.
